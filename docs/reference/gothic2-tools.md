# Gothic II Gold reference

Coverage: original PC Gothic II Gold, including Night of the Raven. These entries do not describe New Balance or other mods.

328 commands and insert references, 58 normal-play item descriptions, and 12 tips. This is a curated selection, not a claim to include every game instance. General cheats, characters/creatures, items, weapons and armor use the existing code categories. Every section supports search; command cards support copying. NPC-only equipment and expansion content are identified in their titles. Named NPC instances distinguish their world/story variant.

Descriptions are independently written. Every insert identifier was checked against its linked reference table on 2026-10-07. No source prose or images were imported. Inserting story objects or NPC copies does not reliably repair quest state.

## Validation

Unit and Compose checks are supplied for catalog integrity, normal-play separation, raw identifier searches, categories and copying. Android builds and those Kotlin tests require Android Studio; they were not run in the editing environment.
